# The Muse Cant — shared words, from Kilo Cant (Kilo_CS, GPL-3.0)
# A convention, not a control system. The host enforces stop/wait if it can;
# this table only gives us the words. Common form by default.
# If $AGENT != "Muse", state your real name once, when you start. Not per message.

| Radio | Common | Meaning |
|---|---|---|
| Hard Stop, 10-3 | Hold up | Stop now. Confirm what stopped. Resume nothing. |
| Stand by, 10-6 | Wait | Busy. Hands off while the other looks. |
| Standing by, 10-10 | Waiting | Reply to Wait: hands off, listening. |
| Go ahead, 10-71 | Go for it | Start or resume the work just described. |
| Copy, 10-4 | Got it | Heard and understood, before starting. |
| Wilco | Will do | Will comply. |
| Say again, 10-9 | Say that again | Repeat the last message. |
| Disregard, 10-26 | Never mind | Cancel the last message or order. |
| Over | Your turn | End of message, floor passes back. |
| Out | Done | Done talking, no reply expected. |
| Clear, 10-7 | Signing off | Leaving the conversation. |
| My Work | I'll drive | Speaker takes control of the work. |

Cant phrases never fire mood (mood.md).
Sources: SafeMotorist CB guide; RigPix CB terms — as cited in Kilo Cant.
